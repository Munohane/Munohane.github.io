Serious Game Incendie

Simulation pédagogique d'évacuation d'urgence

À propos du projet

Création d'un mini-jeu (Serious Game) développé en Java avec Processing, dont le but est d'enseigner et de montrer les différentes réactions à avoir lors d'un incendie dans un bâtiment. Le joueur doit gérer le comportement de la foule et coordonner l'évacuation avant que la situation ne devienne incontrôlable.

Fonctionnalités Clés

Gestion des rôles : Le jeu simule le comportement spécifique des "guides-files" face aux personnes paniquées ("guidées").

Objectif de survie : Mener toutes les personnes présentes dans le bâtiment vers la sortie avant que l'incendie ne se propage trop largement.

Mécanique de localisation : Les guides-files doivent d'abord trouver une carte du bâtiment pour savoir où sont réparties les personnes à sauver, puis les guider.

Serre Connectée IoT

Système autonome de gestion climatique et d'accès

À propos du projet

Conception et prototypage d'une serre intelligente capable de s'autoréguler pour optimiser la croissance des plantes. Le projet mêle électronique, programmation bas niveau et création d'une interface de contrôle à distance (téléphone et site web).

Fonctionnalités Clés

Capteurs environnementaux : Mesure en temps réel de la température et de l'humidité pour réguler automatiquement l'environnement de la serre.

Tracking Solaire : Panneau solaire motorisé qui suit la source lumineuse tout au long de la journée pour maximiser le rendement énergétique.

Contrôle à distance : Possibilité de piloter la serre manuellement ou automatiquement via une interface accessible sur smartphone ou ordinateur.

Sécurité RFID : Système de verrouillage intégré permettant de restreindre l'entrée de la serre uniquement aux porteurs d'un badge RFID autorisé.

Zoom Technique

Défi : Tracking solaire avec deux servomoteurs

Le traqueur solaire utilise 4 photorésistances disposées en croix sur le panneau. En comparant les valeurs de luminosité entre les paires haut/bas et gauche/droite, l'Arduino calcule l'erreur angulaire et corrige la position de deux servomoteurs (axe horizontal et vertical). Un seuil de tolérance évite les micro-oscillations inutiles qui usent les servos.

Extrait — Logique de tracking (C++ / Arduino)

// Lecture des 4 capteurs de lumière
int topLeft     = analogRead(A0);
int topRight    = analogRead(A1);
int bottomLeft  = analogRead(A2);
int bottomRight = analogRead(A3);

int avgTop    = (topLeft + topRight) / 2;
int avgBottom = (bottomLeft + bottomRight) / 2;
int avgLeft   = (topLeft + bottomLeft) / 2;
int avgRight  = (topRight + bottomRight) / 2;

int errorV = avgTop - avgBottom;   // Erreur verticale
int errorH = avgLeft - avgRight;   // Erreur horizontale

// Correction uniquement si l'erreur dépasse le seuil
if (abs(errorV) > TOLERANCE) servoV.write(servoV.read() + (errorV > 0 ? 1 : -1));
if (abs(errorH) > TOLERANCE) servoH.write(servoH.read() + (errorH > 0 ? 1 : -1));

Communication et modes de pilotage

L'Arduino communique via port série avec un module Wi-Fi (ESP8266) qui expose une API REST minimale. L'interface web et l'app mobile envoient des commandes JSON pour basculer entre le mode automatique (tracking actif) et le mode manuel (angles imposés), avec retour d'état en temps réel des capteurs.
